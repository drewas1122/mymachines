Git – En komplett guide

Alt du trenger å vite om versjonskontroll med Git, samarbeid på GitHub, og bruk av Git Bash-terminalen på Windows.

1. Hva er GIT?

Git er et distribuert versjonskontrollsystem designet for å spore endringer i kildekode under programvareutvikling.

Systemet lar flere utviklere arbeide på samme prosjekt samtidig uten å overskrive hverandres arbeid. Fordi det er distribuert, har hver utvikler en komplett kopi av hele historikken lokalt på sin egen maskin.

2. Hva er GitHub?

GitHub er en skybasert plattform for hostingsider og samarbeid rundt Git-repositorier.

Mens Git administrerer versjonshistorikk lokalt, fungerer GitHub som et sentralt knutepunkt i skyen. Utviklere kan dele koden sin, se gjennom andres bidrag via Pull Requests, og holde oversikt over oppgaver og feil gjennom Issues.

3. Hva er Git Bash?

Git Bash er et kommandolinjegrensesnitt (CLI) for Windows-brukere som leverer et Unix-lignende terminalmiljo.

Siden Git opprinnelig ble utviklet for Linux-systemer, hjelper Git Bash Windows-brukere med a kjore standard POSIX/Bash-kommandoer og Git-operasjoner somlos i et felles og konsistent CLI-verktoy.

4. Nyttige Bash-kommandoer

En kjapp referanse over vanlige navigasjons- og filhandteringskommandoer brukt i terminalen.

  • cdNavigerer mellom mapper i filsystemet.
  • lsViser filer og undermapper i gjeldende mappe.
  • mkdirOppretter en ny mappe med spesifisert navn.
  • rmSletter filer eller mapper permanent.
  • cpKopierer filer eller mapper til ny destinasjon.
  • mvFlytter eller gir nytt navn til filer og mapper.
  • pwdViser den absolutte stien til navarende arbeidssituasjon.
  • catViser innholdet av en fil direkte i terminalen.
  • touchOppretter en ny, tom fil eller oppdaterer tidsstempel.
  • clearTommer terminalskjermen for tidligere tekst.

5. Nyttige GIT-kommandoer

De mest brukte Git-kommandoene du trenger i den daglige versjonskontrollen og arbeidsflyten.

  • git initInitialiserer et nytt lokalt Git-repositorium.
  • git clone [url]Kloner et eksisterende eksternt repositorium til maskinen.
  • git statusViser status for endrede filer og uendrede spor.
  • git add [fil]Legger til filer i staging-omradet for commit.
  • git commit -m [melding]Lagrer et oyeblikksbilde (snapshot) av staging-omradet.
  • git push [remote] [branch]Sender lokale commits til det eksterne repositoriet.
  • git pullHenter og integrerer endringer fra det eksterne repositoriet.
  • git branchViser en liste over lokale grener, eller oppretter en ny.
  • git checkout [navn]Bytter arbeidskontekst til den spesifiserte grenen.
  • git merge [gren]Slar sammen den spesifiserte grenen inn i aktiv gren.
  • git logViser en historisk oversikt over commits i repositoriet.
  • git diffViser detaljerte forskjeller mellom ucommittede endringer.

6. Bruk av GIT i VS Code

Visual Studio Code har kraftig innebygd stotte for Git, og forenkler arbeidet med et grafisk grensesnitt.

Du kan bruke "Source Control"-panelet pa venstre side for a se endrede filer, klargjore dem (stage), skrive commit-meldinger og synkronisere prosjektet ditt mot GitHub med enkle knappe-klikk.
